Understanding Confusion Matrix Terminology
TN
True Negative
BENIGN traffic correctly identified as safe.
Result: Normal user sessions uninterrupted.
FP
False Positive (False Alarm)
BENIGN traffic incorrectly flagged as an attack.
Security Impact: Legitimate users wrongly blocked.
FN
False Negative (Missed Attack)
ATTACK traffic missed and classified as BENIGN.
Security Impact: Server overwhelm & downtime.
TP
True Positive
DDoS attack flow correctly detected and flagged.
Result: Attack identified for mitigation.
