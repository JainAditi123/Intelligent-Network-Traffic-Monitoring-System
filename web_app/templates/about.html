Develop Intelligent Network Traffic Monitoring System

Using the CIC-DDoS2019 Dataset and Ensemble Machine Learning Architectures

1. Problem Statement & Research Objectives

The Problem: Distributed Denial-of-Service (DDoS) attacks overwhelm server resources, causing service outages that cost modern enterprises upwards of $20,000–$40,000 per hour. Traditional signature-based firewalls fail against polymorphic attacks, and manual traffic analysis cannot scale to millions of flows per second.

Core Objectives:

  • Implement an automated binary classification system to accurately detect DDoS traffic flows (BENIGN vs. ATTACK).
  • Evaluate single-tree baseline models (Decision Tree) against modern ensemble paradigms (Random Forest, XGBoost, Soft Voting, and Stacking).
  • Validate whether ensemble meta-learning yields superior sensitivity (lowest missed attacks) compared to standalone classifiers.
  • Ensure scientific transparency through reproducible preprocessing, SMOTE class balancing, and an empirical data leakage audit.
  • Provide an interactive web demonstration dashboard with real CSV prediction and calibrated confidence scores.

5. Ensemble Learning Architectures
1. Decision Tree (Baseline): Single recursive binary splitting tree based on Gini impurity. Fast and interpretable, but exhibits higher false alarms (FP=22).
2. Random Forest (Bagging): An ensemble of 100 decision trees trained on bootstrap samples with random feature subsets. Aggregation by majority voting significantly reduces predictive variance (FP=9, FN=49).
3. XGBoost (Gradient Boosting): Sequentially built shallow trees (depth 6) where each tree optimizes a pseudo-residual loss function. Achieves the lowest false alarms (FP=4) and 0.9999 precision.
4. Voting Ensemble (Soft Voting): Computes the unweighted arithmetic mean of predicted class probabilities across DT, RF, and XGBoost: P(c) = (P_DT + P_RF + P_XGB) / 3.
5. Stacking Ensemble (Meta-Learning): Employs DT, RF, and XGBoost as Level-0 base learners. Their cross-validated out-of-fold probability outputs serve as meta-features for a Level-1 Logistic Regression classifier. This model optimizes decision boundaries to achieve the lowest missed attacks among ensembles (FN=46, Accuracy=0.9994).

7. Scientific Limitations & Methodological Findings
⚠️ Feature-Selection Leakage & Empirical Resolution: In Step 4 of the original pipeline, feature selection was performed prior to train-test splitting. Our leakage audit (leakage_free_evaluation.py) demonstrated that 90% (27/30) of features are independently identified on training data alone, and accuracy remains above 99.84%.

Dataset-Specific Distribution: Models are trained on synthetic simulated DDoS scenarios from the University of New Brunswick testbed. Real enterprise networks exhibit diverse background traffic noise that may require domain adaptation.
